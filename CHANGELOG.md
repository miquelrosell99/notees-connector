## 2026-11-08

- **fix(connector): link captures skip identifier extraction; degenerate tabs notify; README signing trade-off.** Final whole-branch review fixes. **Wrong DOI in bibliographies**: a context-menu "Save to bibliography" on a LINK ran `extractIdentifiers(tab.id)` — reading the CURRENT PAGE's `citation_doi`/`dc.identifier` meta and attaching it to the LINK TARGET's URL (a page about X saved the DOI of page Y). `performCapture` now takes `{ isLinkCapture }`, set by the context-menu handler only when `info.linkUrl` is present, and skips extraction in that case (pinned by a test: link capture sends no `extractIdentifiers` call and no `identifiers` key even with a mocked DOI). **Silent outcome**: the degenerate-tab guard (`!tab.id || !tab.url`) returned without a word, contradicting the README's "a notification confirms every outcome"; it now notifies "Nothing to capture here …" (test flipped from "notifies no one" to "notifies, never captures"). **Docs**: the persistent-unsigned install section now states the trade-off — `xpinstall.signatures.required=false` disables signature verification for ALL extensions on that profile; use only on a profile dedicated to self-hosted/development extensions. **Reproducible icons**: `scripts/render-icons.mjs` (+ `pnpm run icons`) regenerates `icon-48.png`/`icon-96.png` dependency-free (hand-rolled PNG encoder on `node:zlib`; the "N" glyph is stroke geometry measured off the shipped 96px icon, since dependency-free SVG text rendering has no font engine). Side effect: it fixes `icon-48.png`, whose previous render was cropped (the N was cut off at the bottom-right corner — it shipped that way from the out-of-band headless render). Verification: full gate green — `pnpm test` 103/103 (15 files), `pnpm typecheck` clean, `pnpm build` clean, `pnpm lint:ext` 0 errors / 0 warnings / 0 notices.

- **feat(connector): build, package, docs — unsigned XPI via web-ext, manifest gecko ID + PNG icons, build-output contract test, README; final-sweep test hardening.** The lane finale lands the shippable artifact and the user-facing docs, plus the controller's final-sweep items. **The pack**: `pnpm run pack` (vite 3-mode build + static copy → `web-ext lint` → `web-ext build`) produces `web-ext-artifacts/notees_connector-0.1.0.zip` — manifest, background, content bridge, options page, icons; `web-ext lint` answers 0 errors / 0 warnings. **The manifest**: a `browser_specific_settings.gecko.id` GUID (clears MISSING_ADDON_ID) and `data_collection_permissions: {required: ["none"]}` (the new Firefox declaration, honestly "none"). **PNG icons**: `icons/icon-48.png`/`icon-96.png` rendered from `icons/icon.svg` (kept as the design source) — the manifest, toolbar, and notification icon all ride PNG now, because several OS notification servers refuse SVG (`notify.ts` switched). **The contract test**: `test/build-output.test.ts` rebuilds and pins every file the manifest references against `dist/`, pins the background bundle content-script-safe (no bare `import`), and pins the bridge's install guard in the shipped bundle. **The README**: install (about:debugging temporary vs persistent unsigned via `xpinstall.signatures.required=false` on Developer Edition/Nightly/ESR — release Firefox honestly refused until AMO signing lands), the settings walkthrough (server URL normalization, `capture.write` API key, toggles, the per-origin permission grant), the two transports (tab relay preferred; REST fallback; definitive answers final; `409 e2ee_required` → "open Notees"), honest limitations, and dev commands (including the `pnpm run pack` vs pnpm's own `pack` tarball trap). **Final sweep**: relay gains the two-capture cross-talk test (two in-flight captures, out-of-order/swapped responses, each resolves its own requestId) and the `removeListener` no-leak assertion (add/remove spies paired, success AND timeout paths); transport gains the two dedicated `feature_disabled` finality tests (relay path — final, REST never called; REST path — passes through untouched); tabs gains the `about:blank`/`chrome://`/`moz-extension:` never-match cases; the bridge's idempotent-install test is now non-vacuous (deletes the guard flag before re-evaluating the module, asserts exactly one listener set); the options page gains the load-on-open path (seeded storage populates every form field); the extractor harvests ISBN-typed `dc.identifier` values (`urn:isbn:…`, bare or hyphenated 10/13-digit, `citation_isbn` still wins) inside `extractInPage` — self-containment preserved.
